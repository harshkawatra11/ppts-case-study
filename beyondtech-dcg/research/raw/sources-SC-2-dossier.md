## Notes on method

- This pass re-used every S500 to S599 source already catalogued by SC-2's original scorecard lane
  (`sources-SC-2.md`) wherever the same document was cited again; only genuinely new documents or
  direct social-media fetches received a new S800-block ID, per PLAN.md section 6.1's instruction that
  each agent owns a non-colliding ID range.
- Two Instagram follower counts recorded as NOT FOUND on the original `college_scorecard_south.csv`
  row for NIT Tiruchirappalli (ProfNITT, 180DC NIT Trichy) and one for NIT Warangal (180DC NIT
  Warangal) were successfully retrieved this pass via a direct WebFetch of the public profile page,
  and are marked CORRECTED in the two dossier files. This does not change either college's Fit score,
  since the model (`model_tables.md` T8) was already run and section 7.6 dossiers are written after
  G3; the lead should decide whether a model re-run is warranted.
- The NIT Warangal "Important Dates" PDF at nitw.ac.in, found via search as the most promising lead
  for a placement calendar, turned out on direct fetch to describe an unrelated faculty-run summer
  research fellowship (₹5,000/month, no hostel), not the corporate placement or internship season.
  It is cited (S811) only for that narrower, correctly scoped fact (RW04), not as placement-calendar
  evidence.
- No number, recruiter visit, follower count, role title or office-bearer name was invented. Every
  NOT FOUND cell in both dossier files reflects a minimum of 3 distinct search attempts, per PLAN.md
  section 0.3 DO item 4. Where a named office-bearer was found on an institution's own public page
  (180DC NIT Trichy's Entrepreneurship Cell term report, 180DC NIT Warangal's branch page), this
  dossier records the role title only and withholds personal contact details, per PLAN.md section 7.6's
  instruction to name a role, not a private person's phone or email.
