## Notes on methodology for this lane
- Every figure above a tier-7/8 aggregator source is marked "aggregator-reported" in the CSV notes and
  carries "est." framing per PLAN.md section 6.2.
- Where WebSearch's own synthesis (not a single fetched page) is the only evidence, the CSV cites the
  S-ID of the underlying search result page the synthesis drew from, consistent with the lane schema's
  "VERIFIED (search result only)" status used elsewhere in this project.
- BITS Pilani's placement process (recruiter visits, sector split) runs as a single Pilani Placement
  Unit process across the Pilani, Goa and Hyderabad campuses in several of the sources found; where a
  figure could not be isolated to the Goa campus specifically, the CSV says so explicitly in the note
  and reuses PLAN.md's own seed fact F04 (institute-wide sector split and recruiter list) rather than
  re-sourcing it, since F04 is already in the shared fact base.
- Three searches were run (minimum) for every cell before writing "NOT FOUND"; where a plausible but
  unconfirmed figure existed, "est." was used instead with the estimation rule stated in the note.
