     A real Slides-specific bug was found and fixed: the kit's addDiagonalWire
     helper
     (figma-deck-kit.js §C, and CLAUDE.md §7.10) assumes Figma rotates a
     rectangle around its
     center — true in Design files, false in Slides, where rotation pivots
     around the node's
     top-left (x, y) corner. Using the Design-file formula produced
     disconnected, wrongly-angled
     wires (visually confirmed on S1's hub-and-spoke). Fixed formula for Slides:
     function addDiagonalWireFixed(parent, x1, y1, x2, y2, color, thickness) {
       thickness = thickness || 2.5;
       const dx = x2 - x1, dy = y2 - y1;
       const length = Math.sqrt(dx*dx + dy*dy);
       const angleDeg = Math.atan2(dy, dx) * 180 / Math.PI;
       const r = figma.createRectangle();
       parent.appendChild(r);
       r.resize(length, thickness);
       r.fills = [{ type: "SOLID", color }];
       r.cornerRadius = 0;
       r.x = x1;                    // start AT point1 (not centered on the 
     midpoint)
       r.y = y1 - thickness / 2;
       r.rotation = angleDeg;       // pivots around (x1,y1), sweeping the far 
     end onto point2
       return r;
     }

     plan's original

     process
     trace, S7 dual hub-and-spoke). addWireH (axis-aligned, no rotation) is
     unaffected and stays
