A lot of open source work goes unpaid, and we wanted to change that, at least for a month. So for Mergetober, we're paying contributors. Everything you build goes into Cognee, a real project that developers and companies around the world use to give their AI agents memory, so your work won't end up in a hackathon repo nobody opens again. You build something that ships, people you've never met end up using it, and you get rewarded for it.

AI models forget. Every call to an LLM starts from zero, with no idea what happened before. Cognee is an open source memory layer for AI agents: you feed it documents, chats, code or data, and it turns them into a knowledge graph of the things in your data and how they connect. Agents can then remember and recall that knowledge across sessions instead of starting fresh every time.

A company brain is only as good as what's plugged into it. Cognee has a handful of data source connectors today, like Notion, Slack and Google Drive, and a long list of tools still waiting to be connected. Every integration you build is one more place whose knowledge AI agents can actually use.

Code shows what you built, and a blog post shows why it matters. We want real stories of how people use these integrations, so the next person knows what's possible.

Two paths, one finish line
What's an integration?
A small piece of code that connects Cognee to another tool. It reads data from somewhere a team already works, like GitLab issues, Linear tickets or files in an S3 bucket, and feeds it into Cognee. Once it's in, AI agents can remember it and answer questions about it.
What we're looking for
Integrations that actually work against a real account of that tool, not just on paper. That means clear setup steps, a working example, tests, and code someone else can read and maintain after you.
Build integrations that plug new tools into Cognee's memory.

You can pick up an existing open issue labelled INTEGRATIONS and hackathon on the Cognee GitHub repo, with connectors for tools like GitLab, Linear, Elasticsearch, Postman, AWS S3 and ClickUp, or you can propose a brand new integration that Cognee doesn't have yet by opening an issue.
